# Third-party notices

`independent-mcp-bridge-all.jar` shades open-source runtime libraries. The deterministic CycloneDX SBOM generated by
`./gradlew generateSbom` lists the exact resolved artifacts, versions, SHA-256 hashes, package URLs, and explicit
license identifiers for a release build. Packaging fails if an exact runtime Maven `group:name` coordinate lacks a
reviewed license mapping or if the reviewed map contains stale entries.

The full reviewed license texts packaged with the JAR are:
